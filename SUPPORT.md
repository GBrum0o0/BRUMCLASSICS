# Ajuda e suporte

Antes de abrir uma issue:

1. Confirme que está usando a Release mais recente.
2. Consulte a BRUMWORLD dentro da aba BRUMNEWS.
3. Abra **Configurações → Sistema** e leia o diagnóstico.
4. Para lojas, confira o estado individual em **Configurações → Conexões**.

## Família Steam

1. Conecte a Steam normalmente com SteamID64 e Web API Key.
2. Na linha da Steam, clique em **ATIVAR FAMÍLIA**.
3. Use **ABRIR TOKEN OFICIAL**, entre na Steam se necessário e copie o JSON exibido.
4. Cole o JSON no launcher e clique em **ATIVAR E SINCRONIZAR**.

O token da sessão é temporário. Quando o botão mudar para **RENOVAR FAMÍLIA**, gere outro token pelo mesmo caminho. A biblioteca própria continua funcionando e o último catálogo familiar válido fica preservado durante a renovação.
5. Para o celular, confirme que computador e aparelho estão na mesma rede e gere um novo QR Code.

Ao abrir uma issue, inclua:

- versão do launcher;
- versão do Windows;
- loja ou plataforma envolvida;
- etapas para reproduzir;
- mensagem de erro sem credenciais;
- captura de tela, quando apropriado.

Não envie ROMs, BIOS, jogos, tokens, cookies ou dados privados.
