# BRUMCLASSICS MÓVEL Android 0.22.0

## BRUM Core integrado

- GB, GBC e GBA agora abrem dentro do BRUMCLASSICS, sem importar o jogo para o RetroArch.
- O núcleo mGBA arm64 é compilado de uma revisão fixada e incluído no APK.
- A ROM original permanece na pasta autorizada; uma cópia privada é preparada automaticamente.
- Tela horizontal completa com modos **Preencher** e **Imagem inteira**.
- Controles virtuais, controles Bluetooth e direcionais físicos.
- Avanço rápido de 5× com áudio suspenso durante a aceleração.
- Saves locais identificados pelo hash real da ROM e acompanhados por manifesto de integridade.
- Horas da sessão retornam ao mesmo registro CLASSICS e continuam disponíveis para sincronização com o launcher.
- Se o sistema ainda não possui core integrado, o aplicativo mantém o fallback atual pelo RetroArch.

O APK é arm64 e requer Android 8.0/API 26 ou superior.
