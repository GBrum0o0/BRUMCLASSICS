# BRUMCLASSICS OFICIAL 1.42.2

## Identidade pública

- A edição publicada no GitHub passa a usar o nome **BRUMCLASSICS OFICIAL**.
- O executável público agora se chama `BRUMCLASSICS-OFICIAL-1.42.2-portable.exe`.
- O pacote completo agora se chama `BRUMCLASSICS-OFICIAL-1.42.2-COMPLETO.zip`.
- O perfil usado para preparar a publicação continua limpo e isolado; contas, tokens, ROMs, saves e dados pessoais não acompanham os arquivos.

## Preparação antes de jogar

- JOGOS e CLASSICS exibem Onde parei, Objetivos, Dicas e Comandos enquanto o processo real é iniciado.
- A preparação usa uma janela dedicada e mantém a interface principal minimizada.
- “Aperte qualquer botão para continuar” só aparece quando o processo do jogo ou RetroArch está realmente pronto.
- Teclado, mouse e controles conectados podem liberar a tela.
- A janela recupera o foco durante a transição para resistir à troca tardia feita por lojas e jogos.
- Se a abertura falhar, o launcher volta ao primeiro plano com segurança.

## Atualização e anotações

- Atualização segura pelo launcher com filtro de versão, SHA-256 e backup recuperável do executável anterior.
- O Perfil do Jogo possui Onde parei, Objetivos, Dicas e Comandos.
- As anotações são sincronizadas com o BRUMCLASSICS MOVEL para consulta offline.
- A BRUMWORLD possui um tutorial visual completo para usar as anotações.
