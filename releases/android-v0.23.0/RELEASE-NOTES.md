# BRUMCLASSICS MÓVEL Android 0.23.0

## Gaming Mode completo

- Jogos instalados no computador podem ser iniciados para jogar no celular.
- O launcher prepara a sessão e o Android abre o Moonlight oficial.
- Sunshine é detectado e diagnosticado no computador sem simular streaming quando estiver ausente.
- O pareamento guarda rede local e Tailscale sob a mesma identidade TLS.
- Fora da rede física, o aplicativo prioriza automaticamente o endereço remoto protegido.
- BRUM Core, tela cheia, avanço 5×, controles, saves e três slots rápidos continuam disponíveis para GB, GBC e GBA.

O APK é arm64, requer Android 8.0/API 26 ou superior e preserva os dados da instalação anterior.
