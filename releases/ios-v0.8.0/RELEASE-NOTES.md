# BRUMCLASSICS MÓVEL iOS 0.8.0

- Central BRUM sincronizada com o perfil ativo do launcher 1.59.0.
- Avisos de conquistas, sessões, saves, instalações, atualizações e sistema.
- Contador na tela Início, leitura individual, leitura completa e abertura do jogo relacionado.
- Atualizações em tempo real e último snapshot disponível offline.
- Compatibilidade de leitura com caches antigos do protocolo 8.
- Nenhuma credencial, caminho local ou identidade de outro perfil é enviada ao iPhone.

O IPA é distribuído sem assinatura para instalação pessoal pelo Sideloadly ou AltStore. O bundle ID e os dados locais permanecem preservados ao instalar sobre a versão anterior.
