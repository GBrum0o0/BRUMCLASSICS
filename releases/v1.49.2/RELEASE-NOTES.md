# BRUMCLASSICS OFICIAL 1.49.2 — Primeiro acesso por cópia

O guia Steam + BRUMWORLD agora acompanha a cópia baixada, e não o perfil de jogador.

| Situação | Resultado |
| --- | --- |
| Baixar/extrair uma cópia nova do GitHub | Guia aparece uma vez, mesmo com contas já conectadas |
| Fechar e reabrir essa mesma cópia | Guia não se repete |
| Baixar novamente, em outra pasta ou substituindo o arquivo | Nova cópia apresenta o guia novamente |
| Atualizar pelo próprio launcher | Visualização anterior preservada |
| Abrir o executável fixo criado automaticamente pelo launcher | Não duplica o guia |

Com contas existentes, escolha **CONTINUAR COM MINHAS CONEXÕES**. Não é necessário reconectar a Steam. Também é possível abrir a BRUMWORLD ou conectar uma conta pelos links oficiais.

Para rever o guia quando quiser: **Configurações → Conexões → ABRIR GUIA DE PRIMEIRO ACESSO**.

## Como testar

1. Feche o launcher em execução.
2. Baixe o pacote 1.49.2 e extraia em uma nova pasta, ou baixe o executável dessa versão.
3. Abra essa cópia: o guia deve aparecer, mesmo se já houver biblioteca no PC.
4. Continue e feche o launcher. Reabra o mesmo arquivo: o guia não deve se repetir.
5. Uma nova cópia baixada/extraída deve apresentar novamente o guia.

O registro utiliza caminho, identidade e timestamps do arquivo externo. Uma restauração que preserve integralmente o mesmo arquivo e seus metadados pode ser indistinguível de reabrir a instalação anterior; nesses casos, use o botão de rever o guia.

Nenhuma conta, biblioteca, coleção, favorito, capa, nota, save ou configuração é apagada. O pacote público não inclui dados pessoais. BRUMWORLD, BRUMNEWS e linha do tempo atualizadas. O APK incluído continua sendo **MOVEL 0.13.1**, sem necessidade de reinstalar se já estiver nessa versão.
