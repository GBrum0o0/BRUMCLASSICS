# BRUMCLASSICS MÓVEL Android 0.18.0

Esta versão adiciona o registro manual de conquistas e requer o launcher 1.61.0 para essa função.

## Novidades

- Busca de conquistas por nome ou descrição dentro do detalhe do jogo.
- Toque em um item bloqueado para marcar a conquista e informar a data histórica.
- Registros manuais podem ser desfeitos; confirmações oficiais continuam protegidas.
- Botão **Cadastrar** para jogos cuja loja não fornece uma lista completa.
- Atualização imediata pelo mesmo perfil pareado no computador.

Instale `BRUMCLASSICS-MOVEL-0.18.0.apk` sobre a versão anterior. O package ID e o certificado permanecem os mesmos, preservando pareamento, biblioteca, ROMs autorizadas, capas, anotações e BRUMMOMENTS.

Requer Android 8.0/API 26 ou superior. ROMs, BIOS, saves e núcleos não são fornecidos.
