# BRUMCLASSICS MÓVEL iOS 0.13.0

## BRUM Core

- Game Boy, Game Boy Color e Game Boy Advance agora abrem dentro do BRUMCLASSICS.
- Não é necessário importar esses jogos para o RetroArch.
- A ROM original permanece na pasta autorizada; uma cópia temporária protegida é preparada automaticamente durante a execução.
- O primeiro core integrado é o mGBA, compilado de fonte oficial e incluído no IPA.
- Controles virtuais, controles Bluetooth, áudio, vídeo e saves `.srm` fazem parte da sessão interna.
- Horas e último jogo continuam sincronizados com o perfil e o launcher.
- Sistemas ainda não integrados mantêm o RetroArch como fallback, sem fingir suporte interno.

O IPA é arm64, sem assinatura e deve ser assinado pelo Sideloadly ou AltStore.
