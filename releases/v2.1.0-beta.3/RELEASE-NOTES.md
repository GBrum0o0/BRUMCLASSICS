# BRUMCLASSICS OFICIAL — atualização de compatibilidade 2.1.0-beta.3

Esta é a atualização intermediária para quem instalou **BRUMCLASSICS BETA 2.1 / 2.1.0-beta.2**. Ela utiliza o mesmo botão de atualização, repositório e mecanismo de download/instalação existentes.

O binário anterior só reconhece tags Beta e o asset `BRUMCLASSICS-BETA.exe`; por isso esta publicação conserva esse formato **apenas para permitir a transição pelo próprio aplicativo**, sem reinstalação manual. O executável apresenta a marca oficial e já aceita o fluxo oficial normal. Beta passa a ser somente codinome de desenvolvimento.

1. Em Configurações → Sistema → Atualizações, clique em **Verificar → Baixar → Reiniciar e atualizar**.
2. Após abrir esta versão, clique em **Verificar novamente**: será oferecida a versão oficial `2.1.0`.
3. Baixe e reinicie para concluir a transição. As próximas versões seguem o fluxo oficial normal.

O perfil anterior, a biblioteca, as contas, as configurações e o Cofre são preservados. Não há troca automática para o perfil de outra instalação nem sobrescrita de outra cópia oficial ao lado. Não remova sua instalação antes de atualizar.

Os recursos do Save Vault e a base BRUM Core PC permanecem incluídos. Não há novo serviço de distribuição, servidor de saves ou sincronização automática. A tag intermediária e o asset legado existem apenas porque o filtro do binário já instalado não pode ser alterado remotamente.
