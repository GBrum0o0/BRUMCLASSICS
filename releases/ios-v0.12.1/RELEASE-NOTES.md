# BRUMCLASSICS MÓVEL iOS 0.12.1

## Navegação e Gaming Mode

- Corrige a barra inferior para respeitar a área segura do iPhone, sem conteúdo vazando por baixo.
- A navegação agora traz Início, Biblioteca, JOGAR, Estatísticas e Companion.
- Perfil e configurações foram movidos para dentro da tela Início.
- Os atalhos B-CARD e CLASSICS Everywhere saíram da Início e continuam disponíveis no Perfil.
- O Gaming Mode agora abre diretamente em orientação horizontal e oculta a barra inferior.
- A seção **No celular** usa somente ROMs realmente encontradas na pasta autorizada.
- A seção **Instalados no computador** usa somente jogos cuja instalação foi confirmada pelo launcher.
- Jogos preservados apenas no cache não aparecem como se estivessem prontos para jogar.
- O botão Sair retorna à interface normal e restaura a orientação vertical.

O workflow macOS gera um IPA arm64 sem assinatura, validado e pronto para assinatura pessoal pelo Sideloadly ou AltStore.
