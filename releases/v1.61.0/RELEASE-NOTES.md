# BRUMCLASSICS 1.61.0 — Seu histórico, do seu jeito

Esta atualização permite registrar conquistas manualmente nos jogos cuja conexão não oferece uma leitura oficial completa, sem misturar esses registros com confirmações oficiais.

## Novidades

- Em **Conquistas**, abra um jogo, pesquise pelo nome ou descrição e marque o item já obtido.
- Escolha a data e a hora reais do desbloqueio, inclusive para conquistas antigas.
- Desfaça somente registros manuais; conquistas confirmadas oficialmente permanecem protegidas.
- Quando a loja não fornece o catálogo, cadastre nome, descrição e pontuação do item.
- Registros são separados por jogador e sincronizados com Android 0.18.0 e iOS 0.9.0 pelo protocolo móvel 10.
- Se uma fonte oficial passar a reconhecer o mesmo item, o launcher promove o registro sem duplicar a contagem.
- O explorador de conexões também foi refinado para declarar claramente o que cada loja realmente oferece e evitar integrações privadas ou não verificáveis.

## Compatibilidade

Biblioteca, jogadores, contas, favoritos, coleções, saves, ROMs, capas, controles e configurações existentes são preservados. O novo protocolo é necessário apenas para os aplicativos móveis desta entrega.

## Instalação

Feche a versão anterior e execute `BRUMCLASSICS-OFICIAL.exe`. O arquivo versionado possui o mesmo conteúdo e existe para conferência.

O pacote não contém contas, tokens, biblioteca pessoal, ROMs, saves ou chaves privadas. O executável não possui certificado Authenticode comercial, portanto o Windows pode apresentar um aviso de reputação.
