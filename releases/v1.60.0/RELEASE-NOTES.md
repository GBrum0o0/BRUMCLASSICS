# BRUMCLASSICS 1.60.0 — Explorar conexões

Esta versão reúne lojas, serviços e emulação no mesmo fluxo de Configurações → Conexões, mantendo a identidade visual do BRUMCLASSICS.

## Novidades

- O painel anterior foi simplificado para uma entrada principal: **EXPLORAR CONEXÕES**.
- Steam, Epic Games, GOG Galaxy, EA app, Ubisoft Connect, RetroAchievements e RetroArch aparecem no mesmo catálogo.
- Busca e filtros permitem localizar uma integração ou mostrar somente as já configuradas.
- Os cartões mostram estado, recursos disponíveis, origem do acesso e funcionamento do monitor.
- Uma etapa de detalhes explica permissões e diagnóstico antes de conectar ou alterar uma integração.
- Conexão, validação, sincronização, desconexão e Família Steam agora exibem progresso visual por etapas.
- Erros mantêm os dados anteriores e devolvem o usuário ao formulário com uma orientação clara.
- RetroAchievements e RetroArch possuem fluxos focados e independentes dentro do mesmo sistema retrô.
- O explorador revalida os estados periodicamente enquanto permanece aberto.

## Compatibilidade

Biblioteca, jogadores, contas, favoritos, coleções, saves, ROMs, capas, controles e configurações existentes são preservados. Os aplicativos Android 0.17.0 e iOS 0.8.1 continuam compatíveis; esta atualização não exige uma nova versão móvel.

## Instalação

Feche a versão anterior e execute `BRUMCLASSICS-OFICIAL.exe`. O arquivo versionado é idêntico e existe para conferência.

O pacote não contém contas, tokens, biblioteca pessoal, ROMs, saves ou chaves privadas. O executável não possui certificado Authenticode comercial, portanto o Windows pode apresentar um aviso de reputação.
