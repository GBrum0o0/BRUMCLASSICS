# BRUMCLASSICS OFICIAL 2.1.0 — codinome Beta

Esta etapa passa a ser uma **atualização oficial do Launcher**, distribuída pelo GitHub e oferecida pelo próprio aplicativo. **Beta é somente o codinome de desenvolvimento**, não uma instalação ou distribuição separada para novas versões.

## Atualizar pelo Launcher

Em **Configurações → Sistema → Atualizações**, clique em **Verificar → Baixar → Reiniciar e atualizar**.

- **Launcher oficial 1.76.0 ou anterior compatível:** encontra diretamente a versão `2.1.0` e o asset `BRUMCLASSICS-OFICIAL.exe`, utilizando o mesmo atualizador existente.
- **BRUMCLASSICS BETA 2.1 / 2.1.0-beta.2:** encontra primeiro a atualização de compatibilidade `2.1.0-beta.3`. Atualize pelo aplicativo; depois clique em Verificar novamente para receber `2.1.0`. A primeira atualização corrige o filtro antigo que aceitava somente prereleases Beta. Não é necessário reinstalar manualmente.
- O perfil da instalação atual é preservado nas duas etapas: biblioteca, contas, configurações e Cofre não são mesclados com outra instalação. Uma instalação Beta anterior mantém seus dados e atualiza somente o seu executável; não sobrescreve outra cópia oficial ao lado.

Cada download tem tamanho, SHA-256 e formato de executável Windows conferidos. O fluxo existente mantém cópia recuperável do executável anterior. Feche os jogos e salve seu trabalho antes de atualizar.

## Recursos desta versão

O **Save Vault / Cofre de Saves** permanece em **Configurações → Save Sync**, com capas, descoberta manual de saves do PC, escolha de outro armazenamento, origem personalizada, scan e prévia antes da cópia, associação ao jogo, seleção dos arquivos, versões divergentes preservadas, escolha manual do save ativo e exclusão confirmada apenas da cópia do Cofre.

Importar não ativa, não restaura no emulador e não sobrescreve o armazenamento original. Definir como ativo registra sua escolha para sincronização manual. Nenhuma sincronização automática, transporte LAN novo, conta online, ranking, servidor externo, Gamepad, segunda tela ou streaming foi adicionado nesta etapa.

A base do **BRUM Core PC** acompanha o Launcher: host nativo, inicialização/comunicação e saves por perfil/hash de ROM. Núcleos compatíveis precisam estar instalados. Não são distribuídos jogos, BIOS, DLLs de emulação ou dados pessoais. O RetroArch e os recursos existentes continuam disponíveis.

Veja o guia `SAVE-VAULT-BETA.md` anexado e [a validação desta publicação](VALIDACAO.md).
